# タイトル・キーワード検証チェックリスト（note SEO）

出典: note SEO検証調査レポート（2026-11-22、~/workspace/research_notes/note-seo-verification-20261122/report.md）
根拠は note公式ヘルプ明記＋2026-11-22の実測（Google・Yahoo!・note内検索）。経験則のみの項目は入れていない。

## 公開前（約15分）

1. **キーワード仮説を2〜3個立てる（3分）**
   - 読者が検索窓に打つ言葉から逆算する
   - 相談室＝「AI 使い方 分からない」系、実録＝「Claude Code 使い方」「note 半自動」系、ニュース＝固有名詞そのもの
2. **note内検索で競合を見る（5分）**
   - note.com/search で候補キーワードを検索し、「人気」順の上位10件のタイトルを眺める
   - 上位に共通する語は、自然に入るならタイトルに取り込む
   - 上位が部数・収益訴求の有料記事ばかりなら競争過多。複合キーワードにずらすか本命を変える
3. **Googleで競合を見る（5分）**
   - 同じキーワードをGoogle検索。上位が公式・大手メディア・Qiita/Zennばかりなら、Web検索での表示は狙わず「悩みの言い回し」タイトルでロングテールとnote内流入を狙う
   - `site:note.com キーワード` でnote内の競合だけを見ることもできる
4. **タイトル最終チェック（2分）** ※公式ヘルプ「タイトルと見出し画像のコツ」に基づく
   - [ ] キーワードが自然な形で入っているか
   - [ ] 前半25文字以内で「何の記事か」と具体性が伝わるか（公式目安は全体15〜25文字。実録の作風では前半だけでも満たす）
   - [ ] 数字やエピソード等の具体性があるか
   - [ ] 誇大表現・煽り・記号での無理な装飾がないか
   - [ ] ハッシュタグは本命キーワードから5つ程度に厳選したか（公式:「5つぐらいが効果的」。観点はタイプ／テーマ／シリーズ名／関連語）

## 公開後（約5分、公開の1週間後を目安）

5. **インデックス確認（2分）**
   - Googleで `site:note.com chinamaru_1995` を検索し、新記事が含まれているか見る
   - 注意: Googleは「似たページ」を省略表示する。表示されなくても未インデックスとは限らない（未確定として記録）
6. **表示圏の確認（3分）**
   - 本命キーワードでnote内検索とGoogle検索をし、上位20〜30件に入っているか記録する。入っていなければ「圏外」と記録するだけ（順位を追いすぎない）
   - noteダッシュボードで流入元の比率だけ確認する。検索クエリ単位の分析は通常アカウントでは不可（公式明記: Search Consoleは独自ドメインのみ）

## 記録フォーマット（1記事1行）

`日付 | 記事 | 本命キーワード | note内表示圏（○/圏外） | Google表示圏（○/圏外/未確定） | 検索流入比率（ダッシュボード）`

数記事分たまると、自分のアカウントで効くキーワードの傾向が見えてくる。

## 実測で分かった前提（2026-11-22時点）
- 彼の記事はGoogle・Yahoo!ともインデックス済み（現行シリーズで少なくとも9本をGoogle表示で確認）
- ただし狙いキーワード（例「Claude Code 初心者」）とタイトルフレーズの自然検索では、両エンジンとも上位10件圏外。note内検索も「人気」順の上位20件は圏外
- note内検索でタイトル完全フレーズ検索をすると自分の記事が唯一の結果として出る（指名検索は機能している）
- 公式は順位を上げる具体策を公表していない。「よいコンテンツを作り続けること」が公式回答
