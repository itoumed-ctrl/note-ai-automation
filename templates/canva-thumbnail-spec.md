# Canvaサムネイル仕様

使い方: この仕様を、Canvaにサムネイルを作ってもらうときの指示のもとにします。AI秘書に発注を任せる場合も、人間が自分でCanvaを触る場合も、同じ仕様を使います。色はシリーズごとに決めて固定します。以下は、私のシリーズで確定した配色の例です。自分のシリーズでは、色の値だけ差し替えてください。

## 1. サイズ
- 1280×670px（noteの見出し画像の推奨サイズ）
- 生成結果のサイズは、必ず目で確認する（正方形で出てくることがあります）

## 2. 配色（白ベース・薄グレー・青アクセント）
- ベース（背景）: 白 #FFFFFF
- サブ（面・区切り・陰影）: 薄いグレー #EEF1F5〜#E2E8F0
- メイン／アクセント: 青 #2F6FDB 前後
- 文字（見出し）: 濃いチャコール〜ネイビー #1F2A37
- 青は差し色として使い、全面ベタ塗りにはしない

## 3. レイアウト
- 見出しは、太めのゴシック体で、濃いチャコール。2行まで。数字を1つ入れる
- 見出しは小さめにして、余白を広くとる（大きくしすぎない）
- シリーズラベル「【シリーズ名】 第○回」は左上に置く。青の細枠＋青文字、または青地に白文字
- 薄グレーの面やラインでバランスをとる
- 装飾は最小限。写真は原則使わない。フラットでモダンな文字中心にする
- シリーズを通して同じレイアウトを使い、回の番号と見出しだけ差し替える

## 4. Canvaへの依頼文（コピーして使う）

noteの見出し画像を1枚作ってください。
- サイズ: 1280×670px（横長。正方形にしない）
- 背景: 白（#FFFFFF）。薄いグレー（#EEF1F5〜#E2E8F0）の面かラインで、余白のバランスをとる
- 見出し: 「【見出し。2行まで、数字を1つ入れる】」。太めのゴシック体、色は #1F2A37。小さめにして、余白を広くとる
- 左上: 「【シリーズ名】 第【○】回」。青（#2F6FDB）の細枠＋青文字
- アクセント: 青（#2F6FDB）を差し色として少しだけ使う。全面ベタ塗りにしない
- 写真、グラデーション、過剰な装飾は使わない

## 5. 生成後の確認（人間が目で見る）
- [ ] サイズが 1280×670 になっている
- [ ] 画像が真っ白になっていない（文字や面がちゃんと出ている）
- [ ] 見出しが2行以内で、数字が入っている
- [ ] 文字が読める（背景とのコントラスト、小さすぎない）
- [ ] 配色が上の確定パレットの範囲に収まっている
- [ ] シリーズ前回までと、レイアウトがそろっている

## 6. うまくいかなかったとき
- 正方形で出てきた: Canvaでリサイズする。無料のリサイズの枠には回数の制限があるので、使い切ることがあります
- 無料のリサイズの枠を使い切った: 原寸のまま書き出して、ローカルで 1280×670 に切り抜く。切り抜いたあとは、見出しが切れていないか必ず見る
- 真っ白になった: 同じ依頼で作り直す。それでも白いときは、依頼文の要素を減らして出し直す
- 色や雰囲気を変えたくなった: 画像を直す前に、STYLE.md の配色を先に更新する
