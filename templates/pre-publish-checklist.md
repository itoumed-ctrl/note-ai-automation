# 投稿前チェックリスト

使い方: noteに入稿する前、公開（予約投稿）の前、公開の直後の3回に分けて、人間が自分の目で確認します。AIの「確認しました」という報告だけで、チェックを入れません。記事ごとにコピーして使います。

記事: 【ファイル名】  確認日: 【YYYY-MM-DD】

## A. 入稿する前（原稿ファイルの確認）

数字と現在地
- [ ] 記事に出てくる数字（記事数、売上、閲覧数など）は、すべて実測値である
- [ ] 取れていない数字は「未計測」と書いてあり、推測で埋めていない
- [ ] 現在地（公開記事数、売上）が、確認した日の実際の数字と合っている
- [ ] 「売れた」「稼げた」「月◯万円」などの収益訴求がない

出典と事実
- [ ] 料金、仕様、日付などの事実に、一次情報（公式ページ）の出典URLと確認日がある
- [ ] 出典URLを、実際に開いて確かめた
- [ ] 公式の文言と実画面が食い違う点は、断定せずに書いてある
- [ ] 未確認のことは、「未確認」と書いてある

AIの開示と実録
- [ ] AIが下書きを書いたこと、事実確認と最終確認を人間が行ったことが、冒頭の近くに書いてある
- [ ] 実際にやっていないことを、やったように書いていない
- [ ] 有料記事が未公開のとき、無料記事に「公開予定」と書き、リンクを付けていない

形式
- [ ] タイトルに数字が入っている
- [ ] 文字数が型の範囲に入っている（無料: 2,500〜4,000字。有料: 無料部分 1,500〜2,000字、有料部分は手順が再現できる量）
- [ ] 公開用ファイル（publish/）に、原稿メモが混ざっていない
- [ ] 太字記号（アスタリスク2つ）が、公開用ファイルに必要以上に残っていない

## B. 有料ラインとサムネイル（有料記事のとき）

- [ ] 有料ラインは「読むと何ができるか」が全部伝わった直後にある
- [ ] 有料ラインは、段落と段落の間にある（段落の途中には置けない）
- [ ] ラインより前だけで、手順の核心を出し切っていない
- [ ] 目印の行「▼ここから有料エリアです」を、入稿時に消した（note側の機能でラインを設定した）
- [ ] 価格を決めた（通常会員は100円〜50,000円。初期方針は980〜1,480円）
- [ ] 手数料と振込条件を踏まえた（クレジットカード決済は事務手数料5%、利用料は（売上−事務手数料）の10%、振込手数料は1回270円。1,000円未満は振込申請できない）
- [ ] サムネイルは 1280×670、確定パレット、見出し2行以内、数字入り
- [ ] サムネイルが真っ白でなく、見出しが切れていない

## C. noteへの入稿のあと（公開の前）

- [ ] 貼り付けた本文で、見出し、箇条書き、引用が正しく変換されている
- [ ] 太字記号（アスタリスク2つ）が、文字として残っていない（残っていたら手で直す）
- [ ] 差し替えたあとも、もう一度同じ確認をした（再発することがある）
- [ ] ログアウトした状態（またはシークレットモード）で、有料ラインの位置と購入ボタンを確認した（投稿したアカウントでログイン中は、購入ボタンが出ず全文が見える）
- [ ] 公開するかどうか、価格、公開日時を、人間が最終判断した
- [ ] 予約投稿を使う場合: noteプレミアム（またはnote pro）であることを確認した。設定画面は、自分の実際の画面で確認した

## D. 公開のあと

- [ ] 公開された記事を、ログアウト状態で開いて、有料エリアが隠れていることを確認した
- [ ] 記事の現在地（記事数、売上）を、実測値で更新する予定を作った
- [ ] 数字が動いたときだけ、動いた数字を書く（動かなかったら動かなかったと書く）
