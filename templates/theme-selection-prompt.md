# テーマ選定プロンプト

使い方: 下の「プロンプト本文」をClaude Codeに貼り付けます。【 】は自分の内容に置き換えます。出てきた案から選ぶのは人間（あなた）です。Claude Codeに「どれにするか」を決めさせません。

## プロンプト本文

あなたは、noteの記事テーマを提案する担当です。CLAUDE.md と STYLE.md を読んでから、次の条件で記事テーマの候補を5つ出してください。

【前提】
- 筆者像: 【例: 31歳、AI初心者。学びながら進める姿勢で書く】
- 想定する読者: 【例: 本業でAIを使いたい、AI初心者の会社員】
- 現在地（実測値のみ）: 公開記事【0】本、有料記事の売上【0】円、フォロワー数【未計測】
- すでにある記事: 【articles/ のファイル名とタイトルを列挙】
- 筆者が実際にやったこと・つまずいたこと: 【事実だけを箇条書き。やっていないことは書かない】

【出してほしい形】
各候補について、次の7項目を書いてください。
1. タイトル案（数字を1つ入れる）
2. 無料記事か有料記事か
3. 読者が読んで「できるようになること」を一文で
4. 書くために必要な事実と、その一次情報（公式ページ）の候補
5. 筆者が実際に体験済みの部分と、まだ体験していない部分
6. 捏造や誇張になりやすいポイント
7. 作業量の目安（小・中・大）

【守ること】
- 実績、収益、閲覧数などの数字を前提にした案は出さない。取れていない数字は「未計測」のまま扱う
- 「稼げる」「月◯万円」などの収益訴求は使わない
- 体験していないことを、体験したように書く案は出さない
- 非公式APIや自動ログインを前提にした案は出さない
- 最後に、5案のうち1本目に向いていると考える案を1つ挙げ、理由を2〜3行で書く。ただし、選ぶのは人間です

## 選んだあとにやること

1. 選んだテーマを、1タスク＝1ブランチ＝1PRの単位で切る（ブランチ名: claude/<内容>）
2. 「4. 必要な事実」の一次情報の確認を、AI秘書に依頼する（handoff-template.md を使う）
3. 確認結果が research/ に残ってから、writing-prompt.md で執筆に進む
