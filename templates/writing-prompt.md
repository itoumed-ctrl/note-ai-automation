# 執筆プロンプト

使い方: 下の「プロンプト本文」をClaude Codeに貼り付けます。【 】は自分の内容に置き換えます。無料記事のときは「有料記事のとき」の行を消し、有料記事のときは「無料記事のとき」の行を消します。

## プロンプト本文

あなたは、noteの記事を執筆する担当です。CLAUDE.md と STYLE.md を読んでから、次の記事を書いてください。作業は新しいブランチ（claude/【内容】）で行い、終わったらPRにしてください。マージはしないでください。

【この記事】
- ファイル名: articles/【free-04 など】.md
- テーマ（タイトル案）: 【選んだテーマ】
- 無料か有料か: 【無料／有料】
- 参照する事実: research/【ファイル名】.md（ここに書いてある事実だけを使う）
- 筆者が実際に体験したこと: 【事実だけを箇条書き】

【記事の型】
- 無料記事のとき: 2,500〜4,000字。全体像、失敗、気づきを正直に書く。最後に次回予告と、有料記事への導線を置く。有料記事がまだ公開前なら「公開予定」と書き、リンクは付けない
- 有料記事のとき: 無料部分は1,500〜2,000字、有料部分は手順が再現できる密度で4,000〜6,000字を目安にする。無料部分の最後（有料ライン）の位置は、「読むと何ができるか」が全部伝わった直後にする。有料部分は、手順、設定ファイル、プロンプト、チェックリストなど、再現できる中身にする
- タイトルには数字を入れる
- 冒頭の近くに、現在地（公開記事数、売上、取れていない数字は「未計測」）と、AIが書いたことの開示を入れる

【有料ラインの指定（有料記事のとき）】
- 有料ラインは、段落と段落の間にだけ置ける
- 公開用ファイル（publish/）には、ラインの位置に「▼ここから有料エリアです」という行を1行だけ入れる
- この行は目印です。noteに入稿するときは、この行を消して、note側の機能でラインを設定します

【書き方】
- 文体と表記は STYLE.md に従う
- 実際にやったことだけを手順に書く。やっていないことを、やったように書かない
- 数字は実測だけ。「売れた」「稼げた」などの収益訴求は書かない
- 事実（料金、仕様、日付）は research/ に書いてあるものだけを使い、ないものは「未確認」と書く
- 太字記号（アスタリスク2つ）は、note貼り付け時に文字として残ることがあるので、公開用ファイルでは必要最小限にする

【成果物】
1. articles/【ファイル名】.md: 先頭に原稿メモ（タイトル案、想定価格、有料ライン位置、使った出典、未確認の点）を HTMLコメントで置き、末尾に出典URLと確認日のメモを置く
2. publish/【ファイル名】-publish.md: 原稿メモを除いた公開用。本文は同一にする
3. PRの説明: 「何を書いたか／根拠にした出典／未確認の点」

## 書かせたあとにやること

1. PRの差分を、pre-publish-checklist.md の項目で人間が読む
2. 事実確認が必要な箇所を、AI秘書に依頼する（handoff-template.md を使う）
3. 直したいときは、記事だけを先に直さず、方向性の変更ならSTYLE.mdを先に更新する
