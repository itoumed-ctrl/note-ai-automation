# 子育てパパの連絡文AIテンプレ集

## 1. この記事で手に入るもの

こんにちは。31歳、AI初心者のまま勉強しながら進めている僕です。「AI自動化の実録」シリーズの、有料記事の3本目です。

子どもが園に通うと、「連絡文」を書く場面が増えます。園の連絡帳と、子どもが熱を出したときの職場への連絡です。朝の忙しい時間や慌てているときほど、言葉が出てきません。

この記事を読み終えると、次のものが手元に揃います。

- 連絡帳の文章を事実メモから整える、基本プロンプト1つとパターン別5つ
- 職場への連絡文を結論から組み立てる、基本の型1つと場面別5つ
- 送る前に確認する、仕上げチェックリスト

テンプレートは、すべて有料エリアに全文を載せています。要約や省略はせず、【 】の部分を自分の内容に書き換えれば使える形です。

AI秘書は、この記事では僕の「Muse」です。「AIが全部書いて送ってくれる」という話ではありません。AIに任せるのは文章にする部分だけで、事実と最後の送信は自分で持つ、という話です。

## 2. 前提と範囲

連絡帳は、毎朝僕が作っています。妻が連絡帳を書くのが苦手なので、僕の担当になりました。AIには下書きを任せていて、段取りは3つです。AIに下書きを作らせる、自分で整える、園のアプリに自分で入れる、の順です。この段取りは、別の無料記事で書く予定です（公開前なので、この記事にリンクはありません）。

中身のルールは1つです。連絡帳に書くのは、見た事実だけ。AIにエピソードを作らせません。子どもの体調や様子も、実際に見たり聞いたりしたことだけをメモして渡します。

職場への連絡文は、今回「一緒に用意したい」と僕が希望して加えました。位置づけは、子どもの発熱など急な連絡で慌てないために、型を用意しておく、というものです。職場への連絡をふだんからAIで書いている、という話ではありません。職場の業種や仕事の内容、具体的なエピソードも、この記事には書きません。

この記事全体で守っていることは、3つです。AIに任せるのは文章化だけで、事実は自分で書くこと。子どもの名前、園の名前、勤務先の名前は、AIに入れないこと。子どもの体調の判断は、AIにさせないこと。テンプレートも、名前の部分は伏せ字の【 】にして、AIから戻ってきた文章に自分で入れる前提で作っています。

## 5. 連絡帳テンプレート

### 5-1. 使い方の流れ

見た・聞いたことだけを1行に1つメモして、基本プロンプトに追加指示とメモを足してAIに渡し、戻ってきた文章を読んで直し、【 】に自分で名前を入れて園のアプリに自分で入力します。

### 5-2. 基本プロンプト（全文）

【 】の中だけ、自分の内容に書き換えます。

```
あなたは、保育園・幼稚園の連絡帳の文章を整える担当です。下の「事実メモ」だけを材料にして、連絡帳に書く文章を作ってください。

【守ること】
- 事実メモに書いてあることだけを使う。書いていないエピソード、様子、気持ち、理由を足さない
- 子どもの名前、園の名前、先生の名前は書かない。「うちの子」「先生」と書く。メモの中の【 】は、【 】のまま残す
- 体調について、診断、原因の推測、登園して大丈夫かどうかの判断は書かない。メモにある事実だけを書く
- メモだけでは書けない所は、勝手に埋めずに【確認：○○】と書いて残す
- 文体は、【です・ます調。丁寧で、くだけすぎない】
- 長さは、【100〜200字】
- 出力は連絡帳の文章だけ。前置きや説明は付けない

【今日のパターン】
【ここに、5-3〜5-7のどれか1つの追加指示を貼る。通常の日なら5-3】

【事実メモ】
【ここに、見た・聞いたことだけを箇条書きで書く】
```

### 5-3. パターン1：通常の日

使いどころ：特別な連絡がない、ふだんの朝です。家での様子を短く伝えます。

追加指示（基本プロンプトの【今日のパターン】に貼ります）：

```
今日のパターン：通常の日
- 家での様子（睡眠、朝ごはん、機嫌など）を、メモにある範囲で2〜3文にまとめる
- 園へのお願いや質問は、メモにあるときだけ書く
- 最後は「本日もよろしくお願いいたします」で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 夜はいつもの時間に寝た
- 朝ごはんはパンとバナナを食べた
- 機嫌はよい
- 連絡事項はなし
```

### 5-4. パターン2：体調が気になる朝

使いどころ：熱、咳、食欲など、いつもと違う様子がある朝です。登園させるかどうかは、園の決まりと、必要なら小児科などの専門家の話をふまえて、親が決めます。AIには決めさせません。このテンプレートは、決めたあとの「伝える文章」を整えるためのものです。

追加指示：

```
今日のパターン：体調が気になる朝
- 「いつ」「何を見た・聞いた」「どうだった」の順で、事実だけを書く
- 体温を測っていれば、測った時刻と数字をメモのとおりに書く
- 診断名、原因の推測、「大丈夫だと思います」のような判断は、書かない
- 薬を使った場合は、メモにある時刻と薬の名前だけを書く
- 園にお願いしたいこと（様子を見てほしい、変化があれば連絡がほしい、など）は、メモにあるときだけ書く
```

事実メモの例（架空の一般例です）：

```
- 朝起きたとき、少し咳が出ていた
- 7時に熱を測ると36.9度だった
- 朝ごはんは、いつもより少なめだった
- 機嫌は普通
- 薬は使っていない
- 変わった様子があれば連絡がほしい
```

### 5-5. パターン3：行事の前日と翌日

使いどころ：行事の前日と翌日の連絡です。前日用と翌日用のブロックのうち、使うほうだけを貼ります。

追加指示（前日用）：

```
今日のパターン：行事の前日
- 行事に向けた家での様子は、メモにあるものだけを書く
- 持ち物、集合時間、体調面の心配など、園に伝えたいことをメモにある順に書く
- 最後は、「明日はよろしくお願いいたします」で結ぶ
```

追加指示（翌日用）：

```
今日のパターン：行事の翌日
- 行事のあとの家での様子（疲れ、睡眠、食欲、機嫌）を、メモにある範囲で書く
- 先生へのお礼は、メモに具体的な出来事があるときだけ、その出来事を入れて書く。メモになければ、短いお礼だけにする
- 最後は、「本日もよろしくお願いいたします」で結ぶ
```

事実メモの例（架空の一般例です。前日用と翌日用）：

```
- 前日：明日は行事の日。家で、練習した歌を口ずさんでいた。早めに寝る予定。持ち物は準備できている
- 翌日：昨日は帰宅後、ふだんより早く寝た。今朝の機嫌は普通。朝ごはんは、いつもどおり食べた。先生に、昨日の行事のお礼を伝えたい
```

### 5-6. パターン4：週明け

使いどころ：月曜の朝です。休み中の様子と、週の始まりのあいさつを伝えます。

追加指示：

```
今日のパターン：週明け
- 休み中の様子（出かけた場所の種類、睡眠、食欲、機嫌など）を、メモにある範囲で2〜3文にまとめる
- 場所や他の人の名前が出てきたら、【 】のまま残すか、「出かけた」のようにぼかす
- 持ち物のお願いや、園への連絡は、メモにあるときだけ書く
- 最後は、「今週もよろしくお願いいたします」で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 土曜は公園に行って遊んだ
- 日曜は家で過ごした
- 夜は、いつもの時間に寝た
- 今朝は、元気に起きた
- 食欲は普通
```

### 5-7. パターン5：先生へのお礼と相談

使いどころ：先生にお礼を伝えたいときと、気になることを相談したいときです。お礼と相談は、1つの文に混ぜず、順番に書きます。

追加指示：

```
今日のパターン：先生へのお礼と相談
- 前半はお礼。メモにある具体的な出来事だけを入れて、短く書く。メモにない出来事は作らない
- 後半は相談。「家で見た事実」→「気になっていること」→「聞きたいこと」の順で書く
- 先生や園を責める言い方、決めつける言い方は使わない
- 相談が長くなりそうなときは、要点だけを書き、「お時間のあるときにお話しさせてください」と結ぶ
```

事実メモの例（架空の一般例です）：

```
- お礼：先生が、持ち物の準備を手伝ってくれたと聞いた
- 家で見たこと：最近、朝の支度に時間がかかる日が続いている
- 気になっていること：園での朝の様子がどうか
- 聞きたいこと：園での様子を、あとで少し教えてほしい
```

## 6. 職場連絡テンプレート

### 6-1. チャット版とメール版の違い

同じ事実メモから、チャット版にもメール版にも整えられます。チャット版は、2〜4文の短文で、結論を最初の1文に置きます。メール版は、件名、宛名、あいさつ、結び、署名が付く丁寧な形です。どちらを使うか、電話が必要かどうかは、職場のルールで決まります。AIには聞かず、自分の職場の決まりで確認してください。

型はどちらも、結論→理由→業務の引き継ぎ→お詫びと感謝の順です。受け取る側はまず「今日どうなるのか」を知りたいので、結論を先に置きます。

### 6-2. 基本の型（全文）

【 】の中だけ、自分の内容に書き換えます。

```
あなたは、職場への連絡文を整える担当です。下の「事実メモ」だけを材料にして、連絡文を作ってください。

【型】
次の順番で書く。
1. 結論：何をお願いするか、どうなるか（休む、遅れる、早退する、など）
2. 理由：子どもの事情を、短く。病状の細かい説明はしない
3. 業務の引き継ぎ：メモにある内容だけ。連絡がつく時間帯があれば、それも書く
4. お詫びと感謝：お詫びは1回だけ。感謝を添える

【守ること】
- 事実メモに書いてあることだけを使う。書いていない理由、予定、約束を足さない
- 勤務先の名前、上司や同僚の名前、子どもの名前、園の名前は書かない。メモの中の【 】は、【 】のまま残す
- 休暇の種類や、休みを取れるかどうかの判断は、書かない。お願いの形にする
- 子どもの体調について、診断や推測は書かない
- メモだけでは書けない所は、【確認：○○】と書いて残す
- 敬語は、丁寧で、くどくならない程度にする

【形式】
【チャット／メール】
チャットは2〜4文で、件名や署名は付けない。メールは件名を付け、宛名、あいさつ、本文、結び、署名の順にする

【今日の場面】
【ここに、6-3〜6-7のどれか1つの追加指示を貼る】

【事実メモ】
【ここに、事実だけを箇条書きで書く】
```

### 6-3. 場面1：朝の欠勤連絡（子どもの発熱）

使いどころ：朝、子どもが熱を出して、今日1日休みたいときです。

追加指示：

```
今日の場面：朝の欠勤連絡（子どもの発熱）
- 結論は「本日、お休みをいただきたい」とお願いする形にする
- 理由は「子どもが発熱したため」程度にとどめ、症状の細かい説明はしない
- 引き継ぎは、メモにある案件と連絡先だけを書く。連絡がつく時間帯がメモにあれば書く
- 急な連絡へのお詫びと、対応への感謝で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 今朝、子どもが熱を出した
- 今日は1日休みたい
- 急ぎの案件は【案件名】のみ。資料は共有フォルダに入れてある
- 連絡は、午前中ならチャットで取れる
```

チャット版の文例（架空の例です）：

```
おはようございます。【自分の名前】です。
子どもが今朝発熱したため、本日はお休みをいただきたく、ご連絡いたしました。
急ぎの【案件名】の資料は、共有フォルダに入れてあります。午前中はチャットで連絡が取れます。
急なご連絡で申し訳ありません。ご対応いただき、ありがとうございます。
```

メール版にするときは、形式を「メール」に変えるだけです。

### 6-4. 場面2：遅刻の連絡

使いどころ：子どものことで、出勤が遅れるときです。到着の見込みを先に伝えます。

追加指示：

```
今日の場面：遅刻の連絡
- 結論は「【時刻】ごろの出勤になる」と、到着の見込みを先に書く
- 理由は「子どもの事情で」程度にとどめ、細かい説明はしない。メモに理由があれば、その範囲で書く
- 遅れることへのお詫びを1回と、感謝で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 子どもの朝の支度が遅れていて、家を出るのが遅くなる
- 出勤できるのは10時ごろになる見込み
- 午前の予定は【予定名】。10時以降に参加できる
```

### 6-5. 場面3：園からの呼び出しで早退

使いどころ：仕事中に、園から連絡があってお迎えに行くときです。

追加指示：

```
今日の場面：園からの呼び出しで早退
- 結論は「園から連絡があり、【時刻】に退社してお迎えに行く」ことを先に書く
- 理由は「園から連絡があったため」程度にとどめる。子どもの症状の詳細は書かない
- 引き継ぎは、メモにある案件と、頼みたい相手の呼び方だけを書く。退社後に連絡がつくかどうかも、メモのとおりに書く
- お詫びを1回と、感謝で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 先ほど、園から連絡があった
- 15時に退社して、お迎えに行きたい
- 15時までに【案件名】を終わらせる
- 【担当の呼び方】に、【案件名】の確認をお願いしたい
- 退社後は、連絡が取りにくい
```

### 6-6. 場面4：翌日以降の休みのお願い

使いどころ：翌日以降も休みが必要になりそうなときです。「決まったこと」と「まだ分からないこと」を分けて書きます。

追加指示：

```
今日の場面：翌日以降の休みのお願い
- 結論は、休みたい期間を「お願い」の形で書く。許可を得る言い方にして、決めつけない
- まだ分からないこと（いつ復帰できるか、など）は、「分かり次第ご連絡します」と書き、見込みを作らない
- 休暇の種類（有給など）や、取れるかどうかは書かない。職場のルールを確認する、とメモにあれば、そのとおりに書く
- 引き継ぎはメモにある内容だけにして、お詫びと感謝で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 子どもの熱が下がらず、明日も休みたい
- そのあとは、明日の様子を見て、またご連絡する
- 休暇の扱いは、職場のルールに従う
- 急ぎの【案件名】は、【担当の呼び方】に引き継いでもらいたい
- 連絡は、夕方ならチャットで取れる
```

### 6-7. 場面5：復帰の報告とお礼

使いどころ：休みのあと、出勤した日の朝です。

追加指示：

```
今日の場面：復帰の報告とお礼
- 結論は「【日付】から通常どおり勤務する」ことを先に書く
- 休んでいた間に対応してもらったことへのお礼を、メモにある具体的な内容を入れて書く。メモになければ、短い感謝にする
- お詫びは1回だけにして、長く謝らない。今後への一言で結ぶ
```

事実メモの例（架空の一般例です）：

```
- 本日から出勤する
- 休んでいる間、【案件名】を対応してもらった
- 【案件名】の続きは、今日確認して引き継ぎを受ける
- お礼を伝えたい
```

```
# 連絡文の仕上げチェックリスト
```

## 8. AIに任せる範囲と、自分で持つ範囲

AIに任せるのは、文章にする部分です。事実メモを、連絡帳や職場連絡にふさわしい言い方に整えるところまでです。自分で持つのは、次の4つです。

- 事実を書くこと。見たこと、聞いたことだけをメモにします
- 名前を入れないこと。子ども、園、勤務先の名前は、AIに渡さず、送る直前に自分で入れます
- 体調の判断をすること。登園するか、休むかは、AIに決めさせません
- 送信すること。連絡帳のアプリへの入力も、職場への送信も、自分の手でします

子どもの個人情報をAIにどこまで渡すか、という線引きは、相談室の第9回「[子育てにAIを使っていいか。パパの3つの線引き](https://note.com/chinamaru_1995/n/n96fc96b93267)」に書きました。名前を入れない、体調の判断をAIにさせない、という約束は、その3つの線から来ています。

「下書きはAI、最後は人間」という同じ考え方で、noteの記事づくりを半自動にした仕組みは、有料記事の1本目「[下書きまで自動、公開は人間。noteを半自動で回す仕組みを6つのファイルで再現する](https://note.com/chinamaru_1995/n/nf0146a681e4b)」にまとめています。

園のアプリの仕様や職場の決まりは、それぞれ違うはずです。【 】の部分と追加指示は、ご自分の環境に合わせて変えてください。
