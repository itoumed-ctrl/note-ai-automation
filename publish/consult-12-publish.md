# 園の行事準備、AIに頼めること3つ

## 行事のお知らせ、あとで読もうと思ってそのままになっていませんか

園から行事のお知らせが届く。プリントだったり、園アプリだったりします。あとでちゃんと読もうと思いながら、日々の忙しさに紛れて、前日になって「持ち物は何だっけ」と探し直す。子育て中の方なら、そんな場面に心当たりがあるかもしれません。

こんにちは。31歳、AI初心者の僕です。この「AI初心者の悩み相談室」は、AIや副業、自動化まわりの悩みに、勉強中の立場から、正直に、できるだけ具体的に答えていくシリーズです。先生として教えるのではなく、「自分はこう考えて、こうしています」をそのままお渡しします。

第12回の悩みは、こちらです。

**「園の行事の準備が大変。AIに頼めることはあるのか」**

僕の子どもも園に通っていて、行事のお知らせはプリントや園アプリで届きます。僕には「プリントから日付・持ち物・提出期限を抜き出すのが負担」という悩みがあります。同じ悩みを解くアプリを検討したこともありますが、開発するかどうかは決めていません。そのかわり、今あるAIで頼めることを整理してみました。

この記事の本文は、AI（Claude Code）が下書きを書き、nihongoというスキルで推敲し、AI秘書のMuseが事実確認をして、最終確認は人間である僕が行います。AIと一緒に作る話なので、その作り方も隠さずに書きます。

**行事の準備でAIに頼めることを、3つお渡しします。あわせて、頼まないことも1つの節にまとめました。専門家の答えではなく、初心者が試している途中の記録です。**

**この記事でわかること**

- お知らせ文から「日時・持ち物・期限」を箇条書きに抜き出す頼み方
- 行事の前日と翌日の連絡帳を、AIに下書きしてもらう段取り
- 当日の朝に見るだけのチェックリストを、前の晩に作っておく方法
- 行事の準備でAIに頼まないこと

## 頼めること1：お知らせから「日時・持ち物・期限」を抜き出す

1つ目は、お知らせ文の整理です。行事のお知らせは文章で書かれていることが多く、必要なのは日時、持ち物、提出期限の3点なのに、挨拶や注意事項の中に混ざっています。この3点だけを拾うのが、僕には一番面倒で、見落としやすいところです。

そこで、お知らせ文のテキストをAIに渡して、箇条書きに整理してもらいます。頼み方はこんな形です。

```
次のお知らせ文から、「日時」「持ち物」「提出するものと期限」だけを箇条書きで抜き出してください。
書かれていないことは補わず、「記載なし」と書いてください。

【お知らせ文をここに貼る】
```

「書かれていないことは補わない」と添えるのがコツです。AIは、足りない情報をそれらしく埋めてしまうことがあるからです。

出てきた箇条書きは、そのまま信じません。元のお知らせと見比べて、日付と数字、持ち物の抜けがないかを自分で確認します。AIの抜き出しにミスがある前提で使います。AIは「整理」を手伝ってくれますが、お知らせの内容に責任を持つのは僕です。

## 頼めること2：行事の前日・翌日の連絡帳を下書きする

2つ目は、連絡帳です。僕は毎朝、園の連絡帳をAIと一緒に作っています。妻が書くのが苦手なので、僕の担当です。段取りは3つで、AIに下書きを作らせる、自分で整える、園アプリに自分で入れる、の順です。この実録は、無料記事「[毎朝の連絡帳をAIと書く。子育てパパの3つの工夫](https://note.com/chinamaru_1995/n/n6da1758e5a57)」に書きました。

連絡帳には、行事の前日と翌日のパターンがあります。

- 前日：持ち物や集合の確認。明日の予定を確認する一言を添えます
- 翌日：先生へのお礼と、家での様子の共有です

どちらも、いつもの段取りのまま回せます。先に自分で事実をメモして、それをAIに渡して下書きにしてもらい、自分で整えて、自分で園アプリに入れるだけです。行事の日だからといって、特別なやり方は要りません。

ここで守っているのは、書くのは見た事実だけ、ということです。「楽しんでいました」「頑張っていました」のようなエピソードは、AIに作らせません。翌日の「家での様子」も、僕が実際に見たことだけをメモにして渡します。見ていないことは書きません。

なお、前日と翌日のパターンは、有料記事のテンプレ集（子育てパパの連絡文AIテンプレ集）にも収録しています。ただ、考え方は上の段取りだけで、テンプレがなくても試せます。

## 頼めること3：当日の朝のチェックリストにする

3つ目は、チェックリストです。頼めること1で抜き出した持ち物を、朝の順番に並べたチェックリストにしてもらいます。頼み方は、たとえばこうです。

```
次の持ち物を、朝に確認する順番に並べて、チェックボックス付きのリストにしてください。
順番は「前の晩に袋へ入れるもの」「朝に入れるもの」「着替え・身につけるもの」の3つに分けてください。
持ち物に書かれていないものは足さないでください。

【持ち物の箇条書きをここに貼る】
```

大事なのは、前の晩に作っておくことです。朝は時間がないので、考えずに上から順に見るだけで済む状態にしておきます。これも、元のお知らせの持ち物と見比べて、抜けや増えたものがないかを自分で確認します。

## 流れは、前の晩までに準備して、朝は見るだけ

ここまでの3つを、1つの流れにするとこうなります。

1. お知らせが届いたら、お知らせ文を渡して「日時・持ち物・期限」を抜き出してもらい、元の文と見比べて確認する
2. 前日に、事実のメモからAIに連絡帳の下書きを作ってもらい、自分で整えて、自分で園アプリに入れる
3. 前の晩に、持ち物をチェックリストにしてもらい、確認する。当日の朝は、見るだけにする
4. 行事の翌日に、見た事実のメモから、お礼と様子の連絡帳を同じ段取りで作る

![行事準備の流れ](consult-12-figure-flow.png)

どれだけ時間が短くなったかは、実測していません。なので「何分短くなった」とは書きません。ただ、「どこで何を確認すればいいか」が決まっているだけで、頭の中の散らかりは減る、と感じています。これは数字ではなく、僕の感覚です。

## 頼まないこと：ここは自分で持ちます

AIに頼めることがある一方で、頼まないと決めていることもあります。この線引きは、相談室の第9回「[子育てにAIを使っていいか。パパの3つの線引き](https://note.com/chinamaru_1995/n/n96fc96b93267)」で書いた3つの線と同じです。

- 子どもの体調や、「行事に参加できるか」の判断は、AIにさせません。迷ったら、園や小児科など、人間の専門家に確認します
- 子どもの名前、園の名前、他の子の情報は、AIに入れません。お知らせ文を貼るときも、名前や園名が入っていたら、消してから渡します
- 行事の感想や子どもの様子は、AIに作らせません。書くのは、僕が見た事実だけです

事実と、最後の送信は、自分で持つ。これだけは、お知らせの整理でも連絡帳でも変えません。

## 正直な留保

ここまでの話には、限界があります。

- AIの抜き出しや並べ替えには、ミスがありえます。だから、元の文との見比べは省かないでください
- 園によって、お知らせの形式も、AIへ入力してよい内容のルールも違います。園や自治体から指示があれば、そちらが優先です
- 使うAIサービスによって、入力した内容の扱いは違います。名前などを入れないのは、そのためでもあります
- ここに書いたのは、あくまで僕の運用です。どの園、どの家庭でも通じるとは限りません
