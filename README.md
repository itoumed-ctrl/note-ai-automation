# note-ai-automation

Claude CodeとAI秘書FRIDAYとCanvaで、noteを半自動で運用する仕組みを作るプロジェクト。
その構築過程自体をnoteの実録シリーズ（無料記事＋有料記事）として発信する。

## 構成
- `CLAUDE.md` — Claude Code向けの執筆ルールとプロジェクト前提
- `series-plan.md` — シリーズ計画（テーマA：AI自動化の実録）
- `first-task-for-claude-code.md` — Claude Codeへの最初のタスク指示書
- `articles/` — 原稿（これから）
- `templates/` — 有料記事の特典テンプレート（これから）

## 進め方
- 1タスク＝1ブランチ＝1PR。マージはユーザーが判断する
- 公開はnoteの予約投稿で人間が行う（noteに個人向け公式投稿APIはないため半自動運用）
- 実績や収益は捏造しない。数字は実測だけ
