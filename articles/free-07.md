# 子どもが寝たあとが僕の作業時間だった。子育て中のパパがnoteを半自動で回す3つの工夫

## 日中に作業時間が取れない、子育て中のパパの運営

こんにちは。31歳、AI初心者のまま勉強しながら進めている僕です。「AI自動化の実録」シリーズの第7回です。

子育て中は日中にまとまった作業時間がほぼ取れません。僕の場合は勉強も作業も、使えるのは子どもが寝たあとの時間だけです。noteの運営も、その時間の中でやっています。

それでも運営が止まらずに回っているのは、気合いで頑張っているからではありません。寝たあとの時間に収まる形まで、やることを減らしてきたからです。この記事ではその実態を3つの工夫として公開します。時間を生み出す魔法の話ではなく、「やることを減らして、限られた時間に収めた」という正直な記録です。

この記事の本文は、AI（Claude Code）が下書きを書き、nihongoというスキルで推敲し、AI秘書のMuseが事実確認をして、最終確認は人間の僕が行っています。

**この記事でわかること**

- 子どもが寝たあとの短い時間を「判断だけ」に絞る、夜の作業の組み立て方
- 朝3時にAI秘書が自動で済ませている準備の中身
- 公開と送信のボタンを最後まで自分で押す理由と、それでも時間が増えたわけではないという正直な限界

## 僕の作業時間は、子どもが寝たあとだけ

先に僕の運営の分担を書いておきます。

- 記事の下書き：Claude Code
- 事実確認と準備：AI秘書のMuse
- 公開の判断と実行：人間の僕

寝たあとの時間が何時間あるのかは実は測っていません。なのでこの記事には作業時間や短縮できた時間の数字は書きません。確かなのは、その時間が有限だということです。有限な時間に毎日の運営を収める必要がありました。

そこで考えたのは「どう頑張って時間を作るか」ではなく、「寝たあとの時間にやることを、どこまで減らせるか」でした。その答えが、次の3つです。

## 工夫1：夜やることを「判断だけ」に絞る

1つ目は、夜の作業を「読んで、直して、決める」だけにしたことです。

下書きづくりと、数字や事実の照合は、AI側に寄せました。ゼロから文章を組み立てる作業は時間も体力も使います。それを子どもが寝たあとの限られた時間に持ち込まないようにしました。

夜の僕がやるのはAIが用意したものを読むこと、気になるところを直すこと、公開してよいかを決めることの3つです。判断は人間に残して、手を動かす部分を減らしたかたちです。

やることが3つに絞られていると、作業の終わりがはっきりします。白紙から書く作業はどこまでやれば終わりなのかが見えにくいからです。寝たあとの時間は有限なので、終わりが見える形にしておくことが大事でした。

## 工夫2：寝ている間に朝の準備を済ませておく

2つ目は、朝の準備を寝ている間に済ませておくことです。

毎朝3時に、AI秘書が自動で準備をしてくれています。中身は次の4つです。

- noteの通知の確認
- 反応をくれた人へのスキとフォローバック（上限つき）
- その日公開する記事の、数字と事実の矛盾チェック
- 公開する記事の選定の補助

僕は朝この報告を読むところから始められます。通知を一つずつ開いて確かめたり、公開予定の記事の数字を一から見直したりする必要はありません。

もう一つの効果は、夜に「明日の分」を抱え込まなくて済むことです。明日の準備を今夜のうちにやっておかなければ、という状態だと、寝たあとの時間はそれだけで埋まってしまいます。朝の準備は寝ている間に済んでいる、と決めておくことで、夜は今日の判断だけに集中できます。

スキとフォローバックは任せる範囲を「反応をくれた人へのお返し」だけに限り、上限もつけています。自動で動かすものには範囲と上限を決めておく。これも、あとで取り返しがつかなくなることを避けるための工夫です。

## 工夫3：最後のボタンは自分で押す

3つ目は、公開と送信のボタンを自分で押すことです。

Xの投稿もnoteの公開もAIには任せず、僕が自分で送信し、自分で実行します。AIに何を任せて、何を承認してから進めて、何を自分でやるのか。この「任せる／承認してから／自分でやる」の3段階の線引きは、相談室の第6回「[AIに任せていいことが分からなかった。初心者の自分が引いた3つの線](https://note.com/chinamaru_1995/n/nc6903ad6f850)」で書きました。ここではこの線引きが「子育て中の運営」にどう効いているかだけ書きます。

理由は2つあります。1つ目は、続ける負担が小さくなることです。最後のボタンを自分で押す形にしておくと、疲れている夜でも「確認して押す」までで終われます。判断が済んだあとに、また新しい作業が待っている形にはしていません。

2つ目は、間違えたときに取り返しのつかない操作を眠い時間の自分に任せたくないからです。公開や送信は、押したあとに取り消しにくいものです。だからこそ押す前に必ず自分の目で確認する。確認したら押して終わり、という流れに固定しておけば、眠い時間の自分も迷わずに済みます。

## 正直な限界：時間は増えていません

ここまで書いてきたことには、はっきりした限界があります。

時間が増えたわけではありません。寝たあとの時間は有限で、やれる量には天井があります。3つの工夫はやれる量を増やすためのものではなく、限られた時間に収まる形にするためのものです。

だから、記事を量産できるようになった、という話でもありません。

もう一つ、続けられている理由についても書いておきます。続いているのは僕の根性や気合いが強いからではありません。仕組みの側にやることを寄せた分が大きいです。気合いに頼る形にしていたら、子どもが寝たあとの時間は、続けるための我慢で終わってしまっていたと思います。

## 同じ子育て世代の方へ

もし今同じように子育てをしながら、何かを続けたいと思っている方がいたら、「時間を作る」より先に「やることを減らす」を考えてみるのはどうでしょうか。僕がやったことは結局そこだけです。

ここまでが無料で公開できる範囲です。下書きまでを自動にして公開は人間が行う仕組みの全文は、有料記事の1本目「[下書きまで自動、公開は人間。noteを半自動で回す仕組みを6つのファイルで再現する](https://note.com/chinamaru_1995/n/nf0146a681e4b)」にまとめています。
